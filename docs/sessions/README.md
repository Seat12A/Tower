# Résumés de session

Chaque session de travail (humaine ou avec Claude) se termine par un résumé dans ce
dossier : `AAAA-MM-JJ-<sujet>.md`. C'est le journal de bord du projet : on doit
pouvoir reprendre le travail en lisant le dernier résumé.

## Modèle

```markdown
# AAAA-MM-JJ — <sujet>

## Objectif
Ce qui était demandé.

## Réalisé
- Changements, avec les fichiers principaux.

## Décisions
- Décision : raison (reporter aussi dans docs/decisions.md si durable).

## Vérifications
- Tests, lint, smoke tests : résultats réels (y compris ce qui a échoué).

## Points ouverts / suite
- Ce qui reste, risques, questions pour l'équipe.
```
